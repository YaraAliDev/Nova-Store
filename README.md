Nova Store 🛍️

A modern and interactive fashion e-commerce website.

🌐 Live Demo

[Click here to visit Nova Store](https://yaraalidev.github.io/Nova-Store/)

✨ Features

* Responsive website design
* Product categories
* Product search and sorting
* Shopping cart
* Quantity management
* Checkout interface
* Simulated payment process

🛠️ Technologies

* HTML
* CSS
* JavaScript

📌 Project Note

This is a front-end e-commerce demo. No real payments are processed.
